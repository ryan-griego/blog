I installed Hermes the other day and wanted to keep it running alongside my OpenClaw agent on the 2015 MacBook Air. Installation has come more naturally because I've done a few OpenClaw installations and there are some similarities in the process — such as selecting the various skills and models it should use. This also included a way for it to pull some data from your OpenClaw agent during setup.

I started using it with the goal of figuring out just how much the Hermes agent knows from the OpenClaw agent. It seems to know many of the things that were in the SKILLS.md and SOUL.md files in OpenClaw. And I haven't yet seen evidence that Hermes is aware of the conversation history between myself and my OpenClaw agent. It looks like most of the OpenClaw commands for working with the CLI are similar to Hermes, which will be nice for already having learned these by working with OpenClaw.

After I got Hermes running, I started a chat with my OpenClaw agent on Telegram and it responded with a pairing code and gave me a Hermes command to run. This immediately made me think I had misconfigured something in the original setup that caused my Hermes agent to take over the Telegram bot I created to chat with it. A few minutes later, I sent another Telegram message and my OpenClaw agent responded and has continued to do so.

The next step for me will be creating another Telegram bot so I can chat with my Hermes agent from my phone.

One of the focuses for me currently is improving my understanding of these agents that run on your computers and what they can do. The question I'm currently answering for myself is what can I do with Hermes that I cannot do with OpenClaw? In what ways does OpenClaw's architecture differ from Hermes? What does the emergence of Hermes after OpenClaw say about the progress of AI? The answers will come soon.
